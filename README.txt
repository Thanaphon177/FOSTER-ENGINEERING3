Foster Engineering website

Open index.html in a browser to start.
Pages: index.html (Home), reference.html, photos.html (Photo Project), contact.html
css/style.css   = styles
js/reference.js = Reference page data (clients and projects)
js/photos.js    = Photo Project list (add a photo: put the file in assets/photos/ and add one line)
js/i18n.js      = Thai text for the TH/EN switch (add data-l="key" in HTML and the key here)
assets/video/   = put hero.mp4 here to play a video behind the Home headline
assets/         = logo and images
